% validates the `titlepage:` / `titlepage-theme:` metadata and fills
% defaults; this partial turns the values into a layout.
%
% Differences from the upstream quarto_titlepages port:
%   - house fonts (sans Montserrat headings, serif body) instead of
%     Latin Modern
%   - house palette via title-color / subtitle-color / ... keys
%   - the classification marking always renders top-right (every page
%     of every format carries it)
%   - single logo block (no duplicate placement), defaulting to the
%     house mark; titlepage-logo: false omits it
%   - a date block renders when `date:` is set
%   - no decorative vertical rule
%   - the house identity line renders at the bottom (docref | edition
%     | review) so the themed page stays traceable
